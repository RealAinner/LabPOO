## Practica 5  
En la practica 5 decidi volver a la tematica del cine y las peliculas pero ahora utilizando lo que se  
solicita en esta practica en la seccion de Elemento de Decision propia y es lo que se explicara a continuacion:  
  
El metodo GenerarResumen() implementa el patron Template Method porque define la estructura  
general para mostrar informacion de una funcion de cine y delega  partes especificas a metodos  
abstractos implementados por las clases hijas. Esto permite reutilizar codigo, evitando la duplicacion  
y mantener una arquitectura mas organizada.
