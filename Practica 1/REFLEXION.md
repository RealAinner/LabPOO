*** Preguntas de Reflexión
1. ¿Qué diferencia hay entre JDK, JRE y JVM? ¿Por qué instalamos el JDK?
	JDK es el que nos permite desarrollar programas en java, viene con el compilador y herramientas
	JRE es el entorno en donde ejecutamos programas java y incluye librerias y el JVM
	El JVM es la maquina virtual y es directamente donde ejecutamos los programas, ademas de converitir el codigo en Bytecode
	Se instala el JDK porque es el que nos deja escribir codigo y compila de java a class
2. ¿Por qué Java es considerado «write once, run anywhere»? Explica con tus
   propias palabras.
	Significa que es multiplataforma, es decir que es portable y se puede ejecutar en diferentes sistemas operativos.
