OP: Que es una abstract class?  
  
IA: Una abstract class (clase abstracta) es una clase que sirve como base para otras clases, pero que no puede crear objetos directamente.  
Se usa cuando quieres definir:  
-Características comunes  
-Métodos compartidos  
-Obligar a las clases hijas a implementar ciertos métodos  
  
OP: Como puedo usar las array o listas en java?  
  
IA: En Java existen principalmente dos formas comunes de almacenar varios datos: los arrays (arreglos) y las listas, normalmente usando ArrayList.  
Un array es una estructura de tamaño fijo. Cuando creas un array debes indicar desde el inicio cuántos elementos podrá almacenar y ese tamaño ya no  
puede cambiar. Los arrays pueden guardar tipos primitivos como int o double, y también objetos de clases.  
  
Los arrays son más simples y ligeramente más rápidos, por eso suelen usarse mucho cuando se está aprendiendo programación o cuando el tamaño de los datos ya es conocido.  
  
Por otro lado, ArrayList es una lista dinámica que pertenece a las colecciones de Java. A diferencia de los arrays, no necesitas definir un tamaño fijo. Puedes agregar  
elementos conforme el programa se ejecuta y la lista crece automáticamente.  
  
Para usar ArrayList normalmente se importa desde java.util.ArrayList. Luego puedes crear listas de tipos simples o listas de objetos.  
Los elementos se agregan usando el método add() y se pueden recorrer también con ciclos.  
  
ArrayList incluye métodos útiles como:  
  
-size() para conocer el tamaño actual  
-get() para obtener un elemento  
-remove() para eliminar elementos  
-isEmpty() para verificar si está vacía  
  
En programación orientada a objetos y proyectos reales, ArrayList suele usarse más porque es más flexible y cómoda de manejar. Sin embargo, los arrays siguen siendo  
importantes para aprender las bases y entender cómo se almacenan los datos.
